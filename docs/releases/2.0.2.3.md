# OpenBlast v2.0.2.3 Release Notes

**Version**: 2.0.2.3 (Build 57)  
**Developer**: Masthan Valli  
**Release Date**: November 16, 2026  
**Target Platform**: Android & Android TV (Android 8.0+)

---

## What's New in v2.0.2.3

- **Jamming Sessions Sync / Unsync**: Added dedicated Sync and Unsync controls for Listen Together sessions. Roommates and friends can now choose to listen independently (unsynced) without disrupting the host, or tap to instantly snap back into perfect lockstep synchronization.
- **Collaborative Playback Control Fix**: Resolved race conditions and desynchronization when the host grants playback control permissions to room members.
- **Persistent Playback Notification**: Restored background playback notification persistence. Swiping or closing the app from recent tasks no longer closes the media notification or halts playback unless explicitly configured in Settings.
- **iOS Sideload Catalog Alignment**: Corrected the SideStore and AltStore repository bundle identifier to match OpenBlast's iOS distribution package, resolving installation mismatch errors.
- **Clean Home Feed**: Suppressed legacy community banner invitations and Discord notices across Android phones, Android TV, and Web interfaces.
- **GitHub Repository Links**: Updated in-app repository links and star actions to point directly to Masthan Valli's repository (Masthan008/OpenBeat).
