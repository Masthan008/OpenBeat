# OpenBlast 1.0.6 Release Notes

**Release Date:** November 7, 2026  
**Version:** 1.0.6 (`versionCode: 48`)  
**Package:** `com.openblast`

---

## Highlights

### 🪔 Authentic Diwali Favorite Animation (Beta)
- Dedicated Diwali celebration triggered whenever a user favorites a track in the player.
- Features a glowing terracotta Diya with dancing multi-layer flame, Anar flowerpot fountain projectile spark physics with gravity and bounce, and radiant spinning Phuljhadi/Chakri celebratory fireworks.
- Clean compact labels in **Settings > Motion and feel > Favorite song animation (BETA)** without text overflowing single-line views.
- Classic default heart burst animation preserved intact.

### 🎛️ New Dock Animations & Dock Icon Styles
- **New Dock Animations:** Added `FLOAT` (gentle hovering elevation lift) and `BOUNCE` (playful rhythmic bounce) to bottom navigation, keeping original `MINIMIZE`, `CAPSULE`, and `SINK` dock motions untouched.
- **New Dock Icon Styles:** Added customizable icon visual styles:
  - **Classic:** Clean original outlined & filled Material navigation icons.
  - **Neon Glow:** Electric accented icons.
  - **Minimal:** Streamlined ultra-clean glyphs.
  - **Festive Sparkle:** Celebratory radiant icons.
- All styles configured under **Settings > Motion and feel > Dock icon style**.

### 🎨 Bespoke Custom Home-Screen Widget Designs
- **Vintage Vinyl Turntable:** Dark titanium deck with brushed gold border, metallic tone arm, and concentric micro-grooved vinyl record disc.
- **Bento Speed Dial:** 4 vibrant color-coded quick-access tiles (Crimson Liked, Sapphire History, Emerald Downloads, Magenta Supermix) for instant 1-tap navigation.

### 🏷️ Application ID & Third-Party Licensing Clean-Up
- Updated Android build application ID cleanly to `com.openblast`.
- Modernized home-screen widget broadcast intent actions (`com.openblast.widget.*`) with backward-compatible legacy aliasing.
- Refreshed all third-party license notices across `THIRD_PARTY_NOTICES.md` to reference OpenBlast.
