# OpenBlast v1.0.8 Release Notes

**Version**: 1.0.8 (Build 50)  
**Developer**: Created by Masthan Valli  
**Release Date**: November 8, 2026  

## Highlights

### 1. Vivo OriginOS & FuntouchOS Center Header Capsule & Origin Player
- **Center Punch-Hole Status Bar Capsule (Origin Island / 灵动胶囊)**: Broadcasts real-time media states (`com.android.music.metachanged`, `com.android.music.playstatechanged`, and `com.android.music.playbackcomplete`) with full track metadata, duration, position, and playback flags.
- **Enhanced Media Notification Provider**: Configured foreground playback notifications with `NotificationCompat.CATEGORY_TRANSPORT`, `VISIBILITY_PUBLIC`, and dynamic ongoing status so Vivo's SystemUI attaches the live header pill around the front camera cutout when backgrounded.
- **Origin Player Desktop & Lockscreen Integration**: Third-party playback controls synchronize seamlessly with OriginOS Walkman and desktop music widgets.

### 2. Real-Time Download Overhaul & Network Selection
- **Download Network Policy**: Added clear selection under **Settings › Library & storage › Download network**:
  - **Wi-Fi and mobile data** (Default / Recommended): Downloads songs over any connection in real time without delays.
  - **Wi-Fi only**: Conserves cellular data by waiting for an active Wi-Fi connection.
- **Resolved "Waiting for Wi-Fi" Lockup**: Fixed the network detection bug where mobile hotspots and metered wireless networks were falsely rejected by `NetworkType.UNMETERED` constraints. Active Wi-Fi transport is now correctly identified.
- **Dynamic Real-Time Connectivity Listener**: Registered a live `ConnectivityManager.NetworkCallback` that detects network availability and automatically triggers queued downloads the moment the phone connects to Wi-Fi.

### 3. iOS Ecosystem Parity & Modernization
- **Project Rebrand**: Updated XcodeGen project configuration (`ios/project.yml`) with `OpenBlast` naming, `com.openblast.ios` bundle identifier, and display name.
- **Developer Attribution**: Added *"Created by Masthan Valli"* inside the iOS Appearance & About views.
- **Sideload Compatibility**: Configured build pipelines for iOS 16+ sideloading via AltStore, SideStore, and Sideloadly.
