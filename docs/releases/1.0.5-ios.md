# OpenBlast v1.0.5 (iOS Edition)

OpenBlast for iPhone and iPad brings high-fidelity streaming, synced lyrics, and ad-free listening to iOS via modern sideloading channels.

### What's New in v1.0.5 (iOS)
- **AltStore & SideStore Sideloading**: Fully verified `.ipa` signed directly on-device using your personal Apple ID or developer certificate without jailbreaking.
- **Synced Lyrics & Audio Engine**: Swift-native lyrics rendering synchronized line-by-line with YouTube Music streams.
- **Lock Screen & Control Center Controls**: Native Now Playing integration via `MPNowPlayingInfoCenter` and remote command handlers for background audio playback.
- **AirPlay & Lossless Audio**: Support for AirPlay 2 streaming to HomePods, Apple TV, and compatible receivers.
- **OpenBlast Sideload Source**: Directly install and receive updates in SideStore and AltStore by adding:
  `https://openblast.vercel.app/ios/source.json`

### Installation Guide for iPhone & iPad
1. **SideStore / AltStore**:
   - Open SideStore or AltStore on your iPhone.
   - Go to **Sources** → **+** and paste: `https://openblast.vercel.app/ios/source.json`
   - Tap **Install** next to OpenBlast.
2. **Direct IPA Sideload**:
   - Download `OpenBlast-v1.0.5-ios.ipa` attached below.
   - Install using Sideloadly, TrollStore, or Xcode on iOS 16.0 or newer.

### Build Verification
- **Package**: `OpenBlast-v1.0.5-ios.ipa`
- **Target OS**: iOS 16.0+
- **Version**: 1.0.5 (Build 5)
