# OpenBlast v1.0.6 (iOS Edition)

OpenBlast for iPhone and iPad brings high-fidelity streaming, synced lyrics, and ad-free listening to iOS via modern sideloading channels.

### What's New in v1.0.6 (iOS)
- **SideStore & AltStore Sideload Alignment**: Corrected the source repository package identifier to ensure flawless installation and update checks in SideStore and AltStore.
- **Official OpenBlast Rebranding**: Complete alignment across app configuration, metadata, and developer attribution under Masthan Valli.
- **Synced Lyrics & Audio Engine**: Swift-native lyrics rendering synchronized line-by-line with streaming audio.
- **Lock Screen & Control Center Controls**: Native Now Playing integration and remote command handlers for seamless background playback.
- **AirPlay Streaming**: Support for AirPlay 2 streaming to HomePods, Apple TV, and external audio receivers.
- **OpenBlast Sideload Source**: Directly install and receive updates in SideStore and AltStore by adding:
  `https://openbeat-site.vercel.app/ios/source.json`

### Installation Guide for iPhone & iPad
1. **SideStore / AltStore**:
   - Open SideStore or AltStore on your iPhone or iPad.
   - Go to **Sources** → **+** and paste: `https://openbeat-site.vercel.app/ios/source.json`
   - Tap **Install** or **Update** next to OpenBlast.
2. **Direct IPA Sideload**:
   - Download `OpenBlast-v1.0.6-ios.ipa` attached below.
   - Install using SideStore, AltStore, Sideloadly, TrollStore, or Xcode on iOS 16.0 or newer.

### Build Verification
- **Package**: `OpenBlast-v1.0.6-ios.ipa`
- **Target OS**: iOS 16.0+
- **Version**: 1.0.6 (Build 6)
