# OpenBlast v1.0.9 Release Notes

**Version**: 1.0.9 (Build 51)  
**Developer**: Created by Masthan Valli  
**Release Date**: November 8, 2026  

## Cross-Platform Release Highlights

### 1. [Vivo OriginOS & FuntouchOS] Origin Player & Status Bar Capsule
- **System Audio Category Registration**: Added `android:appCategory="audio"` and `<category android:name="android.intent.category.APP_MUSIC" />` so Vivo's package scanner registers OpenBlast in **Origin Player (原子随身听)** and Jovi audio source management.
- **Media Button Receiver**: Declared `android.intent.action.MEDIA_BUTTON` intent filter on `PlaybackService` to handle remote headset and widget events.
- **Status Bar Capsule (Origin Island / 灵动胶囊)**: Real-time broadcast events (`com.android.music.metachanged`, `com.android.music.playstatechanged`) and enhanced foreground transport notification feed the animated center punch-hole status capsule.

### 2. [Android] Direct "Download on Wi-Fi only" Toggle Switch
- **Direct Setting Switch**: Replaced the dialog picker with an unmistakable, direct **Toggle switch** in **Settings › Downloads**:
  - **Download on Wi-Fi only** (Default: **OFF**): Songs download immediately on 4G, 5G, or Wi-Fi.
  - When switched **ON**: Downloads automatically pause on cellular networks and wait for Wi-Fi.
- **Auto-Migration**: Existing installations automatically migrate `downloadWifiOnly` to `false` on initial launch of this build, instantly unfreezing downloads.
- **Real-Time Network Callback**: Queued songs begin downloading immediately when network connectivity is established.

### 3. [Web] Player Backdrops & New Accent Themes
- **Fluid Backdrops**: Choice of `Mesh`, `Gradient`, and `Echo glow` backdrops across the player.
- **Expanded Accents**: Added **Electric Violet** (`#7C4DFF`) and **Sunset Coral** (`#FF5722`) to the web player accent palette.
- **Brand Consistency**: Updated settings and interface text to official OpenBlast branding.

### 4. [Android TV] 10-Foot Leanback Experience
- **Landscape TV Mode**: Automatic landscape orientation locking for television displays.
- **Remote D-Pad Navigation**: Full arrow key focus traversal and media playback key control.
- **Performance Tuning**: Dedicated `tvTuned` profile balancing visual aesthetics with high TV framerates.

### 5. [Website] Shipped Notes Platform Tags
- **Color-Coded Badges**: Every release note in the website's Shipped Notes / Releases section is tagged with its target platform (`[Android]`, `[Vivo OriginOS]`, `[Web]`, `[Desktop]`, `[Android TV]`, `[iOS]`).
